# Aiman Syed Website

A responsive static website for GitHub Pages.

## Before publishing

Your contact details and Google Form link are already added.

Optional:
- Replace the downloadable Word guide with a PDF named `Aiman-Syed-Client-Guide.pdf`
- Change the download links in `index.html` from `.docx` to `.pdf`

## Upload to GitHub

1. Open your repository.
2. Click **Add file** → **Upload files**.
3. Upload `index.html`, `styles.css`, `script.js`, and `Aiman-Syed-Client-Guide.docx`.
4. Commit the changes.

## Turn on GitHub Pages

1. Go to **Settings** → **Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`.
4. Click **Save**.

Your site will appear at:

`https://aimansyed1.github.io/website/`
